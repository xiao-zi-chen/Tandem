# Real-task evaluation / 真实任务验证

Tandem is an early desktop release. Downloads and stars do not establish that it saves time or that teams will keep using it. These checks have not yet been completed with external teams.

同序目前是早期桌面版本。下载量与 Star 不能证明省时或持续使用；下面的外部团队验证尚未完成。

## Trial / 试用方式

Invite three teams that regularly change frontend and backend repositories together. Each team brings one real task first, then tries the tool on at least five eligible tasks across two weeks. Keep using existing scripts and editors as a fair comparison.

邀请三个经常同时修改前后端仓库的团队，各先提供一个真实任务，再在两周内尝试至少五个适用任务。与现有脚本、编辑器流程公平比较。

Record installation separately from recurring work. Measure time spent preparing worktrees, returning to interrupted tasks, finding all related PRs and recovering from errors. Separate human effort from machine waits. Include failures and tasks where the team chooses another tool.

首次安装与日常操作分开记录。观察准备工作目录、中断后恢复、找齐 PR 和错误恢复耗时；人工操作与机器等待分开，失败或选择不用同序的任务也计入。

## Evidence to seek / 需要观察的证据

- People use it again in the second week without prompting. / 第二周无需逐次提醒就再次使用。
- Task organization saves enough time to repay installation and learning. / 任务组织节省的时间能覆盖安装与学习成本。
- Another teammate can install it and complete a task without the author operating it for them. / 同事能独立安装并完成任务。
- Existing files, branches and drafts survive interrupted or failed operations. / 中断或失败后已有文件、分支和草稿仍完整。

If existing tools are equally effective, reduce scope or improve interoperability. Record results without private source code, credentials or personal repository paths. This small trial supports product decisions; it is not a market-wide adoption estimate.

若现有工具同样有效，应收缩范围或改善兼容性。记录不包含私有源码、凭据或个人仓库路径。小样本用于产品决策，不用于估算整个市场。
