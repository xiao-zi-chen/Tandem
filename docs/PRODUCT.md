# 0.2 界面与交互调整

这一版按日常桌面工具整理信息层级：导航、任务列表、工作区和差异区域保持固定位置。主要操作用具体动词，状态来自 Git 与本地数据。

## 参考依据

- [GitHub Desktop 官方页面](https://desktop.github.com/)及其[官方产品截图](https://images.ctfassets.net/8aevphvgewt8/3m1LMhekpQUyS0t2CzhCWF/8bc214fc510eeaa79504d9daa192bf6c/desktop-hero-bottom.webp?fm=webp)：实际查看了仓库/分支状态、文件列表与差异并列的布局，参考其固定操作位置和清晰的变更归属。
- [OpenAI 官方 worktree 文档](https://learn.chatgpt.com/docs/environments/git-worktrees)：参考其本地目录、工作副本和交接来源/去向的明确区分。OpenAI 官网桌面介绍页被访问挑战拦截，本次没有据此声称检查了该页面的全部视觉设计。
- [Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)与[应用分发文档](https://www.electronjs.org/docs/latest/tutorial/application-distribution)：用于桌面进程隔离、运行时与安装包结构。

本产品使用自己的名称、图标与代码，保留针对多仓库任务的组织方式。

## 具体变化

| 原版问题                             | 0.2 的处理                                                                 |
| ------------------------------------ | -------------------------------------------------------------------------- |
| 大标题、插画和宣传式句子占据工作区域 | 使用「任务」「仓库」「设置」等明确标题，首次启动只保留实际设置步骤         |
| 大片低对比度绿色、卡片层层嵌套       | 使用中性灰白、明确文本对比度和小范围状态色；仓库改为表格，任务改为紧凑列表 |
| 差异阅读区较窄，文件列表堆在上方     | 桌面上文件列表与差异并排，分别滚动，并增加文件筛选                         |
| 仓库组合点击行为不明确               | 点击名称筛选任务，单独的加号用于从组合创建任务                             |
| 备注切换/刷新时可能丢失              | 保存本地草稿，检测并发版本，展示最新已保存内容供比较                       |
| 文件选择和导出依赖网页能力           | 使用原生文件夹、保存对话框和剪贴板                                         |
| 应用需要手工启动本地网页             | 提供独立窗口、菜单、运行时、快捷方式和 Windows 安装包                      |

中英文同时覆盖菜单、界面、提示和导出；用户自己输入的文本不自动翻译。示例任务明确标注，PR 无法核实时保留「未确认」，归档不删除文件。

## 产品验证

安装包和自动化测试证明了当前实现能运行，不代表已经验证市场需求。后续仍应按[真实任务验证计划](EVALUATION.md)比较任务耗时和连续使用。代码签名、自动更新与其他操作系统的发布需另行完成。
