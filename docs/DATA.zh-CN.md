# 数据与恢复

[返回首页](../README.zh-CN.md) · [English](DATA.md) · [快速上手](QUICKSTART.zh-CN.md)

同序在本机保存工作台元数据。数据目录中也包含真实的任务 worktree，请将它视为项目工作数据。

## 数据保存在哪里

桌面版默认使用当前用户的应用数据位置。在「设置 → 数据目录」中查看实际路径；它不一定与安装包或源码目录位于同一位置。

```text
data/
  state.json          仓库、任务与操作日志
  state.backup.json   上一份有效元数据快照
  workspaces/         真实任务 worktree 与编辑器工作区文件
  sample-project/     可选示例仓库
```

从其他位置连接的仓库仍在原路径，接入的已有工作目录也留在原处。为任务创建的 worktree 是关联原仓库的真实 Git 工作目录。

## 已有的保护机制

- 元数据经过校验，同步写入临时文件后原子替换，并保留上一份有效快照。
- 切换任务时保留备注草稿；保存时检查任务版本，避免静默覆盖其他编辑。
- 操作日志记录未完成的 worktree 创建；恢复仅移除该操作创建且仍未新增工作的资源，已有分支与新工作会保留。
- 无效状态会被保留，不会静默重置为空白工作台。

**元数据快照不备份源码、未提交文件或备注草稿。** 请另行备份项目数据，不要删除数据目录来重置界面。关联 worktree 也依赖原仓库；移动或删除任意一侧的目录都可能破坏关联。

## 恢复元数据

主状态文件缺失或无效时，桌面版先校验备份，再提供「恢复备份并重启」。损坏的原文件会保留。恢复的快照可能早于最近的任务修改，恢复后请检查任务列表与工作目录。

如果界面提示操作中断，使用「检查并恢复」并查看结果；已有新工作的资源会保留。若无法完成恢复，请保留目录，[反馈错误](https://github.com/xiao-zi-chen/Tandem/issues/new?template=bug_report.yml)时移除私人数据。

## 切换工作台

选择「设置 → 打开其他工作台…」，然后选择已有的同序数据目录或空目录。普通非空项目目录与正在使用的数据目录会被拒绝。此操作切换数据目录，不移动仓库或 worktree。

旧浏览器预览版的 `.tandem/` 目录请保留；退出使用它的服务，再从桌面版选择该目录。源码中的 `启动同序.cmd` 优先使用桌面构建，缺少桌面构建时才回退到浏览器预览；安装包用户无需使用这个启动脚本。

## 升级与归档

安装新版本前请退出正在运行的软件。**0.4.0 使用数据格式 2**，与 0.3 一致。旧格式 1 在首次修改时迁移，保留原始 `state.v1.backup.json`；迁移后应继续使用 0.3 或更新版本。

归档任务只将它从进行中的列表隐藏，不删除 worktree 或分支。安装器配置为卸载时保留应用数据；请仍然做好自己的备份，不要通过卸载来清理 Git worktree。
